03 // The Universal Adapter

Xero API Compliance.

Xero Draft Bill Payload
{
  "Type": "ACCPAY",
  "Contact": { "Name": "Apple Store" },
  "LineAmountTypes": "Inclusive",
  "Status": "DRAFT",
  "LineItems": [
    {
      "Description": "MacBook Pro",
      "Quantity": 1,
      "UnitAmount": 1200.00,
      "AccountCode": "720",
      "TaxType": "INPUT2"
    }
  ]
}

Injects directly into Xero as an unapproved DRAFT.

Strict API compliance: Uses INPUT2 for 20% VAT on expenses (never hallucinating invalid codes).

Sets LineAmountTypes: "Inclusive" so Xero doesn't artificially inflate the £1200 gross amount into a £1440 error.
